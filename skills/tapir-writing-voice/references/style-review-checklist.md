# Tapir 写作声音复核清单

## 硬性检查

- [ ] 没有模板化对立句式；
- [ ] 没有中文破折号；
- [ ] 中文引用全部使用「」；
- [ ] 分号和冒号数量很少，每一处都有保留理由；
- [ ] 标题、小标题、摘要和图注也遵守规则；
- [ ] 代码、命令和原始引文没有被错误改写。

## 声音检查

- [ ] 开头交代真实需求、问题或个人动机；
- [ ] 每个重要观点都有实践、截图、代码、对比或具体事件支撑；
- [ ] 技术价值和现实局限都被说明；
- [ ] 没有为了戏剧性否定真实成功；
- [ ] 没有为了励志把失败包装成必然成功；
- [ ] 关键判断处有适量个人口吻；
- [ ] 没有机械堆叠「就是」「然后」「我觉得」；
- [ ] 普通段落完成一个解释单元，没有大量一句一段；
- [ ] 给读者解释了「为什么」；
- [ ] 结论限定在作者的经验和证据范围内。

## AI 腔检查

- [ ] 没有空泛时代背景；
- [ ] 没有连续三段结构相同的排比；
- [ ] 没有为了金句制造虚假对立；
- [ ] 没有翻译腔隐喻；
- [ ] 没有假亲密表达；
- [ ] 没有伪深刻情绪判断；
- [ ] 没有用「真实存在」宣布抽象概念；
- [ ] 没有使用缺少事实支撑的宏大词；
- [ ] 没有把普通步骤包装成宏大方法论；
- [ ] 没有重复总结读者刚刚读过的内容。

## Tapir 特征检查

- [ ] 能看见作者真正做过什么；
- [ ] 能看见作者在哪个节点改变判断；
- [ ] 至少出现一个具体产品、工具、界面或操作细节；
- [ ] 对热点和营销话术保持警惕；
- [ ] 给出适用范围、限制或当前未验证项；
- [ ] 删除作者名字后，文章仍不会变成通用 AI 爆款文。

## 插图检查

- [ ] 难以用文字讲清的结构、界面或过程有插图辅助；
- [ ] 每张图回答一个明确问题；
- [ ] 每张图都在正文中被解释；
- [ ] 图注说明读者应该看哪里；
- [ ] 实机、测试、订单和报错没有被 AI 示意图替代；
- [ ] 图片来源、隐私和授权已经检查。

## 最终人工问题

1. 这篇文章像 Tapir 真正坐下来写的，还是像 AI 在表演 Tapir？
2. 有没有一句话虽然好听，但作者平时不会这样写？
3. 有没有一个观点可以用更具体的项目事实替代？
4. 有没有一段只负责制造情绪，没有提供新信息？
5. 作者读到哪一段最可能说「这不像我」？
