# 常见 AI 腔改写示例

## 对立金句

禁用：

```text
AI 改变的不是工作的速度，而是我们进入陌生领域的勇气。
```

推荐：

```text
AI 当然提高了工作速度，但对我影响更大的是另一件事。我开始敢于进入陌生领域。
```

## 破折号补充

禁用：

```text
系统给出了一个 PASS 状态，视觉上非常专业，却没有回答最关键的问题。
```

推荐：

```text
系统给出了一个 `PASS` 状态，视觉上非常专业。但它没有回答最关键的问题。这块板到底能不能生产？
```

## 引号

禁用：

```text
我当时真的觉得自己“如鱼得水”。
```

推荐：

```text
我当时真的觉得自己「如鱼得水」。
```

## 过度文学化

偏离 Tapir：

```text
那一刻，物理世界终于向我露出了冰冷的獠牙。
```

推荐：

```text
到了贴装流程，系统一次报出六十多个问题，价格也明显升高。我完全不知道这些问题是否需要处理，更不知道 AI 给出的修改是否可靠。
```

## 机械口语化

偏离 Tapir：

```text
然后我就是觉得吧，这个东西就是其实还是挺有意思的，然后我就又继续做了。
```

推荐：

```text
这个方向确实挺有意思，所以我继续做了下去。
```

## 绝对化结论

偏离 Tapir：

```text
AI 已经彻底改变了硬件开发，任何人都能独立完成产品。
```

推荐：

```text
AI 降低了进入硬件开发的门槛，但完整产品仍然需要原理图、PCB、结构和制造等专业判断。至少在我的这次尝试里，这几个环节都需要我理解并验收，单靠生成文件还不够。
```

## 伪深刻情绪

偏离 Tapir：

```text
真正刺痛我的，是专业门槛终于露出了獠牙。
```

推荐：

```text
看到六十多个系统问题时，我才发现自己没有能力验收这块板。AI 可以继续改，但我无法判断它改得对不对。
```

## 空泛总结

偏离 Tapir：

```text
在这个技术快速迭代的时代，我们每个人都需要拥抱变化。
```

推荐：

```text
这次尝试让我更敢进入陌生领域，也让我更早确认自己缺少什么判断。下一次再做类似项目，我会先定义验收方式，再决定哪些步骤交给 AI。
```
